# Q 수치 계산기

기자용 윈도우 프로그램입니다. 증감률을 계산해 기사 문장까지 만들어 주고, 큰 숫자 읽기·면적·외화 환산을 한 화면에서 처리합니다.
표기는 아주경제 스타일북(2021년판)과 교열 기준을 따릅니다.

## 기능

증감률 탭
- 금액·수량의 증감률(전년 동기 대비 등), 비율끼리의 변동 폭(%p)
- 기사 문장 3가지 자동 생성 (클릭하면 복사), 글자수 표시(60자 초과 시 경고)
- 서술어 유형: 실적·수량(증가·감소), 금리(인상·인하), 가격·지수(상승·하락)
- 확정/전망 구분 (전망은 전망 주체를 밝히는 문장으로)
- 기준값 0, 음수, 적자·흑자 전환, 상대 시점 표현, 비교 기준 누락 안내
- 여러 건 붙여넣기: 엑셀에서 복사한 표를 한꺼번에 계산
- 복사한 계산은 이 PC에만 기록 (최근 계산 칩, 기록 보기)
- 설정: 증감 숫자 색(빨강·파랑 / 색 없이 화살표만), 기본 소수점

단위·환율 변환 탭
- 큰 숫자 읽기: 1234500000000 ↔ 1조2345억원
- 면적: ㎡ ↔ 평
- 외화 환산: 1000만 달러(약 138억원), 환산 기준 환율·기준일 표시
- 현재 환율 가져오기: 버튼을 누르면 안내 창(시장 참고 환율, 전송 정보 없음)을 보여 준 뒤 open.er-api.com에서 환율을 받아 와요. 실패하면 직접 입력한 값을 그대로 두고 안내만 띄워요. '다시 보지 않기'를 고르면 안내 창은 이후 생략돼요

## 표기 규칙 (스타일북 반영)

- 만·억·조는 한글로 숫자 뒤에 붙이고 쉼표를 쓰지 않음: 1조2345억원
- 원·명 같은 한 글자 단위는 붙이고 달러 같은 두 글자 이상 단위는 띄움: 1만명, 10만 달러 (분기는 예외로 붙임)
- 외화는 어림수에 약을 붙여 괄호로 원화 환산: 500엔(약 4600원), 유효숫자 3자리
- 시점은 절대 날짜로, 증감률에는 비교 기준을 붙임
- 반올림은 사사오입(4.25 → 4.3)

스타일북에 규정이 없어 임의로 정한 값: %p 표기, 소수점 기본 1자리, 가구 등 두 글자 단위 띄어쓰기, 외화 환산 유효숫자 3자리

## 개발과 빌드

구성
- calccore.py: 계산과 문장 만들기 (화면과 무관, 테스트 대상)
- app.py: PySide6 화면
- make_icon.py: assets/icon_master.png에서 아이콘과 icon_data.py 생성
- installer.iss: 설치 파일 (UTF-8 BOM + CRLF 유지)

테스트
    python -m pip install -r requirements.txt pytest
    python -m pytest -q tests

설치 파일 만들기
- GitHub에 올리면 Actions(.github/workflows/build-installer.yml)가 테스트 후 QNumberCalc-Setup.exe를 만듭니다. (수동 실행 또는 v로 시작하는 태그)
- 내 PC에서는 build.bat 실행 (Python, Inno Setup 6 필요)
